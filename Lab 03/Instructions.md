### **Objective**

Design and implement a small application that uses a **local Large Language Model (LLM)**
 to perform a language-related task. The objective is not only to use an
 LLM, but to build a complete system around it, integrating processing
steps and a user interface. You are encouraged to reuse this exercise as
 part of your course project.

### **Requirements**

Your application must meet the following criteria:

* Use a **local LLM**
  (e.g., Ollama, LM Studio, or Hugging Face running locally). The choice
  of model, configuration, and suitability for the task will be evaluated.
* Provide a **graphical user interface (GUI)**
  for end users. Command-line interfaces or raw APIs are not sufficient.
  You are encouraged to use tools presented in class (e.g., Streamlit,
  Gradio).
* Address a **language-related task**,
  but go beyond a simple prompt-response interaction. The system should
  include some added value, such as preprocessing, postprocessing,
  embeddings, retrieval, prompt engineering strategies, or multi-step
  pipelines.

### **Deliverables**

* **A ** **technical report written in markdown** **, converted into a ** **PDF** **, including:**
  * Problem description
  * System design and workflow
  * Model selection and justification
  * Implementation details (tools, frameworks, decisions)
  * Discussion of results, limitations, and possible improvements
  * Screenshots of the application (and optionally intermediate steps)
* Optionally, a **short screencast** demonstrating the application.
* All work must be included in your digital portfolio, with frequent and meaningful commits reflecting your development process.

### **Evaluation Criteria**

Your work will be assessed based on: technical quality,
appropriateness of the LLM and configuration, system design beyond
simple prompting, usability of the interface, clarity and completeness
of the documentation, and evidence of iterative development.

### **Final Remark**

Approach this as a real NLP system: focus on making well-justified design decisions, not just a working prototype.
